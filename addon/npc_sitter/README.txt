NPC Sitter 1.2 - Garry's Mod

CHANGES IN 1.2
- Added rotation offset: Pitch, Yaw and Roll.
- LMB on an occupied seat applies both position and rotation offsets.
- Position: X/Y/Z. Rotation: Pitch/Yaw/Roll.

USAGE
1. LMB an NPC.
2. LMB a seat.
3. Adjust X/Y/Z and Pitch/Yaw/Roll.
4. LMB the occupied seat to update the NPC immediately.

RMB releases the NPC. Reload clears selection.
